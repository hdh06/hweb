# 4.20
Consider a multicore system and a multithreaded program written using the many-to-many threading model. Let the number of user-level threads in the program be greater than the number of processing cores in the system. Discuss the performance implications of the following scenarios.
   1. The number of kernel threads allocated to the program is less than the number of processing cores.
		**Answer:** Reducing performance because more cores can be used to increase the number of threads. 
   2. The number of kernel threads allocated to the program is equal to the number of processing cores.
		**Answer:**  Optimized and be able to used all the resource available. 
   3. The number of kernel threads allocated to the program is greater than the number of processing cores but less than the number of user-level threads.
		**Answer:** Some threads in the kernel-level must be stalled, waiting for any cores that free up, thus decreasing the performace.
