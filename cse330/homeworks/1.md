Question: Give two reasons why caches are useful. What problems do they solve? What problems do they cause? If a cache can be made as large as the device for which it is caching (for instance, a cache as large as a disk), why not make it that large and eliminate the device?

Answer: 
- With faster speed and smaller size compare to the main memory, cache can help to store data that frequently used to help speed up the load and store process.  
- Instruction cache help to hold the instruction expected to execute next, save several cycles from fetching the instruction from the main memory.

- However, cache management is very important: proper management help to increase the performance but there are several issues. For example: data between the different data hierarchical may appear differently, espeacially in a multitasking system; it is more complicated in a multiprocessor environment as there are as many as cache for each core so data must be sync between them and the main memory.
- Because the larger the memory size, the slower the speed so cache cannot be big.
